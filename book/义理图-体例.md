# 义理图体例（道德经）

定于 2026-11-19。承《论语》图示规矩（`骨架方案.md` 第七节「图示体例」），按《道德经》的骨架改造。

## 一 为什么画

文字讲到「关系」「对比」「流转」时，一句话要绕三层才说得清；一张图只放一个关系，读者一眼看完，再回去读字。图不替代文字，也不承担排版；它是给读者对位用的。

反过来说：这一章若只是「某个字有意思」「某段历史有背景」，不画。**图出必附读图一句**。

## 二 硬规格

| 项 | 定值 |
|---|---|
| 版式 | 竖排单版，`viewBox` 宽 380，高按内容（约 420–640） |
| 纸色 | `#F8F3E6` |
| 四色 | 墨 `#2F2A24`、赭 `#A2503B`、青 `#4A5C55`、线 `#DCCBB0` / `#E6D8C2` |
| 字号 | 题签 11、主标 21、副题 10.5、正文 10–13，**不小于 9.5** |
| 字体 | 思源宋体优先，退宋体；题签用黑体，字距 3 |
| 页头 | 三段固定：`第 N 章 · 类目`（赭、字距 3）／主标题／一句副题 |
| 数量 | 每章**最多一张**；第一章总纲可三张（总纲、读法、观法各一） |
| 载体 | 手写 SVG，`book/义理图/*.svg`；内嵌进阅读版时**只嵌一份**，不引外链 |
| 生成 | 一律用 `tools/make_yili_svg.py` 算坐标，不手填零散数字 |

## 三 图的四种句型

《道德经》全书反复用的是这四种关系，图也只做这四种：

1. **同出**（一个源，两种名）：无、有；妙、徼；体、用。画法：一个上源，分叉两个下位，再收束回一个结论。
2. **相生**（两端互生，不居一环）：难易、长短、高下、音声、前后；「反者道之动」。画法：两栏并列，双向箭头，禁止画成因果单向。
3. **层级**（一段一段往下掉，或一层一层往上显）：道→德→仁→义→礼；徼的层层显化。画法：竖轴 + 刻度标签，上下列清，不画成阶梯图。
4. **三境／三宝**（同一件事的三种站法）：指月三境；慈、俭、不敢为天下先。画法：三段等高，逐段减一笔（手渐无、字渐淡），最后一段只留所指之物。

## 四 禁用

- 不画神像、老子像、人物肖像；不画符箓、八卦图当装饰。
- 不用生成模型出图，不用外链字体或图片。
- 不在图上写整段话；一段超过三行即改文，不改图。
- 不把「无」画成空白方块，不把「道」画成光圈；象要落在具体关系上。
- 一图不并两义；要并，出两张。

## 五 与另外两本书的关系

- **《论语》**：一讲一图、按需出图（2026-11-19 已改）；本编沿用，不逐章硬配。
- **《心经》**：器喻（五蕴杯／管）是 **3D 可交互模型**（`daokedao-xinjing/docs/models/`），不是平面 SVG。本书**附论一「心法锚定（杯喻）」**直接复用该模型，不再另画平面杯；平面图只做「壁与腔」的剖面示意。
- 凡跨书复用，标明出处；不复刻别人的名相。

## 七 第二批排期（按「文字讲不清」优先）

优先做的是关系最硬、读者最容易读反的章：

1. 第十一章 车、器、室：利与用的分工（三容器并列，同出）
2. 第四十章 反者道之动：传动装置（相生，闭环）
3. 第四十二章 道生一至三生万物：生发总图（层级 + 同出）
4. 第三十八章 道→德→仁→义→礼：五级滑落（层级）
5. 第二十五章 道法自然：四条「法」的次序（层级）
6. 第六十七章 三宝：慈、俭、不敢为先（三境）
7. 第七十七章 张弓：上弦不使力（层级）
8. 第八十一章 不积：仓与泉（相生）
9. 第五十一章 道生德畜：生而不有（同出）
10. 第二十二章 曲则全：守曲抱一（相生）

其余各章按需补，不凑数。

## 八 验收

- 每图能在不读正文时独立看懂一个关系；
- 图上不出现两义；
- 380 宽、字号不小于 9.5、无外链、无位图；
- 与正文用词一致（无、有、妙、徼、玄、反、损、啬等，一律照书内用法，不另造译名）。
