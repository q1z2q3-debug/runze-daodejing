# 版本库（_versions）

原则：**每一版都留，任何一版都不删。**

## 存什么
正册每一幅义理图的全部历史版本，按章分目录：

```
_versions/ch01/ch01-wu-you.v2.9.104.svg
_versions/ch01/ch01-wu-you.v2.9.110.svg
_versions/ch02/ch02-liu-zu.v2.9.106.svg
```

- 文件名格式：`<图名>.v<版本号>.svg`，版本号取当时的 `VERSION`。
- 现行版在 `book/义理图/` 里（不带版本号的那个文件），历史版全在 `_versions/`。
- 同一图同一版本只存一份；快照脚本幂等，重复跑不会多出副本。

## 三条不可让
1. **改图之前先快照**。任何要动 `book/义理图/*.svg` 的复核、返工、修订，先跑 `python3 tools/snapshot.py <章号>`。
2. **只增不删**。旧版本即使已被新版取代，也原样留着——它是"当时为什么这么画"的唯一证据。要撤一幅图，也是复制进本库后改动现行版，不是删历史。
3. **四类留档并存，各司其职**：
   - `_versions/`　改图前的原样（同图多版，按时间叠）
   - `old/`　　　　被否的整幅稿（作废，附缘由）
   - `_refs/`　　　参照稿（子虔版仿画、备选模型，不入正册）
   - `book/义理图/` 现行版（每图一份，不带版本号）

## 台账
`book/义理图-版本总表.md` 由 `tools/version_index.py` 生成：每幅图的现行版本、历史版本数与版本清单。改完图、快照完，重跑一次即可。
