# 子虔版参照稿

来源：用户提供的《道德经解（子虔版）》PDF（WPS 演示稿），第一章自第 17 页起，观妙图在第 23 页。
用途：**参照与学习**，取它的骨架（十字轴、红蓝双曲线、太极、两端「恒有欲／恒无欲」），不取它的结论。
身份：**不计入正册 243 幅**。正册只认 `tools/make_yili_svg.py` 的 FIG 键。

十九级序（用户点名要全，不可缺级）：
量子 · 元素 · 原子 · 无机小分子 · 有机大分子 · 蛋白质 · 细胞 · 组织 · 器官 · 五脏六腑 · 人体 · 家庭 · 团体·企业 · 国家 · 文明 · 生态圈 · 地球 · 星系 · 宇宙

两处判断（作图依据，改图前先看这两条）：

1. **交点必须落在「人体」**，不是随便一处。理由：到了这一级才有「观者」，此前全是被观。
2. **三段色面按「人怎么知道它存在」分，不按大小分**：须用仪器看的／肉眼与身体直接可及的／看得见进不去的。
