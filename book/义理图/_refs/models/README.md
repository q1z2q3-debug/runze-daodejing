三条不可让的口径（作图时已写进图里，改图须守）：

1. **「空」与「无」分用字**。讲器用、讲被结构围出来的那一处，写「**空**」；「**无**」只留给本体那一层（未分化、无边界、本自寂静）。混用会把第一章的根说虚。
2. **「无中生有」只作理上的原点，不作事上的先后**。否则与书稿「不是先有无再生有」正面冲突。
3. **「三」不作数读**。一、二、三不是三个东西；三＝二之间的「和」（冲气以为和）。以化学作比：原子为二，键为三，分子以上为万物——此是**比**，不是等同。

另有一处须在体例定谳：「三」在注家有数读（天地人／阴阳冲气／形气神），本书取「冲气以为和」一读，一处不得两说。
