三张图共守的口径（备选的也守，入册的更要守）：

1. **「空」与「无」分用字**。器用、被结构围出来的那一处写「**空**」；「**无**」只留给本体那一层（未分化、无边界、本自寂静）。
2. **「无中生有」只作理上的原点，不作事上的先后**。否则与书稿「不是先有无再生有」正面冲突。
3. **「三」不作数读**。三＝二之间的「和」（冲气以为和）。以化学作比：原子为二，键为三，分子以上为万物——此是**比**，不是等同。注家另有天地人／形气神诸读，本书取「冲气以为和」一读，一处不得两说。
