# 原版备份（_backup）

规矩三条：

1. **先备份，再修改**。任何一章的义理图在动刀之前，先把该章全部 SVG 原版复制到 `_backup/chNN/`，文件名后缀记明版本，例如 `ch01d-yong-xian-pan-ju.v2.9.104.svg`。
2. **一章一审一落地**。复核完一章即提交一章（含原版备份、改定图、复核账、单章页），不攒批、不跨章混提交；全书八十一章逐一落地后，最后再做一次汇总（总目、阅读版、站点）。
3. **备份不删、不改**。备份只增不动；若某章再返工，新备份记新版本号，旧备份原样留着。被否的整幅稿仍按老规矩撤入 `_old/`（原 `old/`），与"同章原版快照"分开：前者是作废的稿，后者是修改前的原样。

版本对照：`VERSION` 文件记当前版本，备份文件名记该章被改前所属版本。
